# How to use

> This registry is designed to be imported into your Kasm Workspaces installation to provide a suite of security-focused tools.

Detailed instructions on creating a registry can be found at the [Kasm Workspaces Registry Template GitHub](httpss://github.com/kasmtech/workspaces_registry_template?tab=readme-ov-file#1-create-your-own-repository).

🔸**How to install 3rd party registries:**
[https://kasmweb.com/docs/latest/guide/workspace_registry.html#rd-party-registry](https://kasmweb.com/docs/latest/guide/workspace_registry.html#rd-party-registry)

🔸**Your Registry URL:**
`https://druzza-d.github.io/kasm-security-registry/1.1/`

# Available containers

| Name | Description |
| :--- | :--- |
| **BloodHound** | An analysis platform for Active Directory trust relationships. Upload data from the SharpHound collector to visualize attack paths. |
| **CyberChef** | The Cyber Swiss Army Knife - a web app for encryption, encoding, compression and data analysis. |
| **Kali Linux (Core)** | A lightweight, Kasm-optimized version of Kali Linux with a core set of tools. Ideal for lower-resource environments. |
| **Metabigor** | An OSINT tool that doesn't rely on API keys. Useful for gathering information about IP addresses, domains, and email addresses. |
| **Metasploit Framework**| The world’s most used penetration testing framework. This workspace launches directly into the msfconsole. |
| **OWASP ZAP** | The OWASP Zed Attack Proxy (ZAP) is one of the world’s most popular free security tools for web application security testing. |
| **Parrot OS** | A full desktop environment with a comprehensive suite of security tools for penetration testing and digital forensics. |
| **Radare2** | A complete framework for reverse-engineering and analyzing binaries; composed of a set of small utilities that can be used together or independently. |
| **Recon-ng** | A full-featured Web Reconnaissance framework written in Python, complete with independent modules and database interaction. |
| **REMnux** | A Linux toolkit for reverse-engineering and analyzing malicious software. |
| **theHarvester** | A tool for gathering OSINT such as e-mail accounts, subdomain names, and employee names from public sources. |
| **Viper Framework** | A binary analysis and management framework with both a terminal and a web interface for malware analysis. |

# Support

This registry is maintained only by me, so please be understanding. If you see something is not working as intended or you have an idea to extend the registry, please create an issue and I will triage it when I have the time.

I put my effort to make sure everything contained in this repository fulfills its purpose, but supply chain disruptions happen. Please do your own due diligence before importing anything to your workspace.

That said, this registry works within Kasm Workspaces, which is the intellectual property of Kasm Technologies, and part of the issues (like infrastructural or not related to these specific workspaces) should be addressed by Kasm Technologies. Depending on your license, please make sure you report issues via the right channel.
